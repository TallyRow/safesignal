> ## ⚠️ DO NOT file vulnerability details in this public issue.
>
> Public submissions expose the vulnerability before a fix can be
> prepared, creating a window during which consumers are unprotected.

## Reporting a vulnerability

**Email `security@tallyrow.com`** with vulnerability details. This
address routes to the maintainer-owned inbox under the
`tallyrow.com` domain.

The full disclosure policy — what to include in the report,
response-time targets, embargo window, supported versions — is in
[`SECURITY.md`](../../SECURITY.md). Read it before sending the
email so you know what to expect.

If you have a **non-sensitive** question about the security
policy itself (e.g., "is this still current?", "what's the
supported-versions range right now?"), you may use this public
issue. The maintainer will respond here.
